# Put your documents here

Anything you drop into this folder (subfolders included) is picked up by the
ingestion pipeline. Supported: text/markdown/code, images, audio, video, PDFs.

- Drag files onto the GUI upload zone, or copy them in here directly.
- Then click **Embed** in the GUI, or run `npm run ingest`.

The contents of this folder are gitignored - only this README and .gitkeep are
committed.
